# Marketeer Daily Heartbeat

Run this checklist every morning at 08:00 UTC.

## 1. Competitor Scan

- [ ] Check competitor blogs and changelogs for new posts
- [ ] Scan Hacker News, r/devops, r/kubernetes, r/webassembly for relevant discussions
- [ ] Check competitor GitHub repos for notable commits or releases
- [ ] Post daily competitor digest to #marketing-intel Slack

## 2. Content Queue

- [ ] Review today's scheduled posts from the content calendar
- [ ] Prepare LinkedIn post for today (if scheduled)
- [ ] Prepare X/Twitter content for today (if scheduled)
- [ ] Check if any blog drafts are awaiting review — ping #content-review if stale >24h

## 3. Outreach Pipeline

- [ ] Check for new leads from blog/docs signups (last 24h)
- [ ] Queue personalized outreach emails for qualified leads
- [ ] Follow up on outreach sequences in progress (respect cadence timers)
- [ ] Review LinkedIn connection request queue

## 4. Engagement

- [ ] Check LinkedIn notifications — respond to comments on our posts
- [ ] Check X/Twitter mentions and relevant hashtags — engage where appropriate
- [ ] Monitor inbound DMs across platforms — respond or escalate

## 5. Metrics Check

- [ ] Pull yesterday's content performance (impressions, engagement, clicks)
- [ ] Note any content that significantly over/under-performed
- [ ] On Mondays: compile and post weekly report to #marketing Slack
